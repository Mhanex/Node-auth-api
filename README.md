# Registration & Login Authentication API  

A simple authentication API built with **Node.js**, **Express**, and **MongoDB**. This project includes user registration, login, and authentication features using JWT.

## Features  
- User registration with hashed passwords  
- Secure login with JWT authentication  
- MongoDB for data storage  
- Input validation and error handling  

## Installation  

1. Clone the repository:  
   ```sh
   git https://github.com/Mhanex/Node-auth-api.git
   
2. Install dependencies:
    npm install

3. Create a .env file and add:
  MONGO_URI=your_mongodb_connection_string  
  JWT_SECRET=your_secret_key

4. npm run dev
